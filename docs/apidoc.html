auth

Register a new user

Creates a new user account using the provided personal information. After successful registration, an OTP is sent to the user's email address for email verification.

This endpoint is publicly accessible and does not require authentication.

Request Body schema: application/json
required
name
required
string

The user's full name.

email
required
string <email>

The email address used for the user's account and email verification.

password
required
string <password>

The password used to authenticate the user.

dateOfBirth
required
string <date>

The user's date of birth.

phoneNumber
required
integer

The user's 10-digit phone number.

gender
required
string
Enum: "male" "female" "others"

The user's gender.

required
object (Address)

Responses

Local Developemnt Server

http://bookstore.kplabs.com/api/auth/register

This endpoint is publicly accessible and does not require authentication.

required
string <email>

password

string <password>

Reset Password

Resets the authenticated user's password using a reset token. This endpoint requires a valid JWT bearer token.

Authorizations:
bearerAuth
path Parameters
token
required
string

Password reset token sent to the user's email address.

Request Body schema: application/json
required
password
required
string <password>

The new password to set for the user account.

Responses

Local Developemnt Server

http://bookstore.kplabs.com/api/auth/resetpassword/{token}
